Группы

Домены

Группа задаётся строкой [имя], следом interface = ... — политика Keenetic либо сетевой интерфейс. Дальше домены: обычная запись охватывает и поддомены, *.имя только поддомены, =имя точное совпадение.

Серверы

Ссылки vless:// по одной в строке либо подписка целиком. При нескольких серверах выбирается самый быстрый. Конфиг проверяется ядром до применения: негодный не заменит рабочий.

Подсети

Для сервисов с зашитыми адресами, которые не спрашивают DNS, — там перехват ответов бессилен.
